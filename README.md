# Google Search Ranking and Discoverability Capstone

This repository contains the code and published research paper for the Google Search Ranking & Discoverability Capstone project.

## Repository Structure
- `submission/paper_url.txt`: Contains the live deployed URL of the research paper.
- `work/capstone_notebook.ipynb`: Jupyter Notebook with complete ML pipeline and analysis.
- `index.html`: Web-ready HTML source for the research paper deployed on Vercel.

## Data Attribution
Built on the FlyRank ML Internship dataset (https://flyrank.ai).
